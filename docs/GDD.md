# Ember Street GDD — v0.3.0

## 产品定义

**Cozy 末日避难街模拟经营 × 七格即时配给。**

一句话：**白天养一条避难街，晚上守七格配给台。**

传播钩子：**只有七格，你能在尸潮夜里把最后一盏灯守到天亮吗？**

## 体验目标

- 10–15 秒：第一次三合与第一份幸存者请求。
- 60–90 秒：一个夜晚完整结束。
- 3–5 分钟：完成建设 / 分工 / 下一夜准备的中循环。
- 10–20 分钟：看到街区与主灯塔明显成长。
- 第一章：DAY 1–7，最终进入「尸潮之夜」。

## 三层循环

### 微循环：七格

货架点取 → 七格占位 → 三合升级 → 交付请求 → Combo / 极限出餐 → 尸潮压力变化。

永久规则：**主配给台只有 7 格，绝不通过常规成长扩到 8 格。**

满格时允许玩家主动「紧急清台」：前两次清除低阶物资换空间并付出小代价，第三次才提前结束本夜，避免软死局和恶意失败。

### 中循环：一天

天亮 → 查看预报 → 修复设施 → 调整幸存者岗位 → 立即结算白天准备 → 进入下一夜。

岗位：搜索 / 修理 / 诊疗 / 守夜 / 炊事 / 广播 / 休息。随着人数增加解锁一键按专长与尸潮班表，避免管理家务化。

### 宏循环：第一章

DAY 1：第一盏灯，学习七格。

DAY 2：搜索窗口，第一位长期幸存者留下。

DAY 3：第一次夜袭，守夜和街区防御开始重要；流浪猫出现。

DAY 4：伤员涌入，诊疗价值上升。

DAY 5：停电预警，电力订单成为重点。

DAY 6：尸潮接近，进入明确准备日。

DAY 7：90 秒「尸潮之夜」。守住后第一街段完成；失败不死档，可重整岗位和设施后重试。

## 建筑

- 主灯塔：唯一核心成长轴。
- 搜索站：补给生产与第一名幸存者入口。
- 修理工坊：零件生产。
- 诊疗站：医疗收益。
- 守夜岗：降低尸潮压力增长。
- 宿营屋：情绪与休息空间。
- 广播亭：预报 / 希望 / 后续内容入口。
- 七格配给站：夜晚核心操作，不做传统建筑升级扩格。

修复建筑必须同时产生数值、视觉与目标变化，不能只显示“+5%”。

## 幸存者

首章固定 6 名长期角色：林夏、老周、阿禾、程医生、阿梁、小满。

他们不是抽卡英雄，没有稀有度、星级、装备和战力。每人只有擅长岗位、精力、心情与一条可记住的特长。

## 尸潮设计

尸潮逻辑采用 0–100 的压力值，不创建大量独立僵尸 AI。画面中的尸影、围栏、警报与灯光只承担规模表现。这样既保持紧迫感，也控制移动 Web 性能。

重大压力必须有预告；失败只能让当夜提前结束或收益降低，不摧毁长期存档。

## 正反馈

- 三合：微反馈。
- 完成请求：希望 / 零件 / 减压。
- 8 秒 Combo：连续服务带来额外希望。
- 极限出餐：最后 15% 耐心交付，额外希望并明显减压。
- 建筑修复：灯火等级与街景一起变化。
- 幸存者加入：新的岗位与角色关系。
- DAY 7：第一章大反馈，「这条街，还活着。」

## 留存

- 轻量离线收益最多 6 小时，只在街区阶段结算，不自动推进尸潮。
- 流浪猫 → 常驻猫 → 镇街猫「小灰」提供低成本连续记忆。
- 每日挑战使用标准化 60 秒配置，与主线存档隔离。

## 社交与分享

不依赖服务器排行榜。

- Seeded PRNG 保证可复现。
- 每日日期映射到固定 Seed。
- `ES1-...` 挑战码含规则版本、Seed、成绩与校验。
- Canvas 本地生成 1080×1440 PNG 分享卡。

## 明确不做

首个比赛版不做：联盟、PVP、真实联网排行榜、账号、抽卡、战力、体力墙、广告复活、付费加速、复杂 3D、开放世界、真实大规模僵尸寻路、100 个建筑或 DAY 100 的空内容。

## 比赛版冻结标准

DAY 1–7 必须完整、移动端可玩、主线可存档、每日挑战可复现、分享图可本地生成、CI 的 typecheck / tests / production build 全绿。达到这些条件后停止增加大系统，只处理 QA、性能、视觉和提交链路。
