# Ember Street GDD — First Light

## 产品钩子

**白天养一条避难街，晚上守七格配给台。**

玩家第一次打开后应在 10–15 秒内完成首个三合与第一份幸存者订单；NIGHT 1 结束后第一次看到完整街区，形成“原来后面还有东西”的惊喜。

## 当前核心循环

货架点取 → 七格占位 → 三合升级 → 自动满足当前需求 → 获得希望/零件 → 尸潮压力变化 → 天亮 → 街区修复。

## First Light 完成条件

1. 七格本身可连续点击且没有输入锁。
2. 第一份订单用三个起始罐头即可完成。
3. 防线订单与幸存者订单使用同一核心逻辑，但给出不同压力收益。
4. 夜晚 75 秒结束或尸潮压力到 100 时进入结算。
5. 结算后进入街区，零件足够时修复搜索站并解锁 NIGHT 2。
