# Ember Street GDD — v0.4.0 Survival Narrative

## 产品定义

**文字末日生存模拟 × 避难街经营 × 七格守夜。**

一句话：**白天决定这条街怎么活，晚上亲手守住只有七格的配给台。**

传播钩子：**只有七格，守住最后的灯火。**

## 核心节奏

游戏刻意采用「静 → 动 → 静」：

```text
清晨日志
→ 白天街区与人物分工
→ 1 个核心文字事件
→ 黄昏准备
→ 60–90 秒七格守夜
→ 天亮结算与余烬日志
```

白天用于阅读、判断和承担后果；夜晚才承担高频操作。不能让所有系统同时刷新。

## 生存状态

长期资源只保留：

- **口粮**：居民日耗、部分事件、夜间准备基础。
- **药品**：事件治疗与夜间一次医疗容错。
- **零件**：修复建筑、防线与电力相关事件。
- **希望**：长期街区生命力 / 进度，不作为普通商店货币。

另有两个当下状态：

- **防线 0–100**：直接降低尸潮压力增长。
- **电力 0–100**：过低时直接提高尸潮压力增长。

UI 优先显示「短缺 / 吃紧 / 稳定 / 稳固」和「还能撑几天」，数值作为辅助。

## DAY 1–7

### DAY 1 · 最后一盏灯

- NIGHT 1 学会七格与三合。
- 天亮第一次看到余烬日志。
- 白天事件「坏掉的路灯」。
- 修复搜索站后，林夏愿意留下。

### DAY 2 · 搜索者

- 林夏参与西街搜索。
- 事件「废弃药店」提供风险 / 安全 / 放弃三种选择。
- 高风险搜索可以造成可恢复轻伤。

### DAY 3 · 第一声撞击

- 老周与围栏压力进入主线。
- 事件「第一声撞击之后」。
- 防线不再只是数字，直接影响夜晚。
- 小灰开始出现。

### DAY 4 · 伤员

- 程医生与医疗事件进入主线。
- 事件「一个发烧的陌生人」。
- 药品成为道德选择与夜间容错资源。

### DAY 5 · 黑暗

- 事件「停电预警」。
- 电力状态进入核心策略；低电力使尸潮增长更快。

### DAY 6 · 广播

- 广播确认大规模尸群接近。
- 事件「尸潮正在靠近」。
- 玩家在口粮、防线、电力与希望之间做最后准备。

### DAY 7 · 这条街，还活着

- 90 秒尸潮之夜。
- 主要请求数增加到 7。
- 所有白天准备转化成容错和压力变化。
- 成功后第一街段灯火达到 Lv.7。
- 失败不删档，可回到白天重新准备。

## 七格守夜

永久规则：**主配给台只有 7 格，绝不常规升级到 8 格。**

三条物资链：

```text
罐头 ×3 → 热食包 ×3 → 战地餐
绷带 ×3 → 急救包 ×3 → 救护箱
电池 ×3 → 电力包 ×3 → 应急电源
```

4 个货架采用 **3 件同类一批**：

```text
罐头 ×3 → ×2 → ×1 → 才补下一批
```

请求节奏：

- DAY 1：3 个主要请求，首单约 30 秒。
- DAY 2–6：5 个主要请求。
- DAY 7：7 个主要请求。
- 成功后约 2.5 秒安静期；错过后约 3 秒安静期。

保留：Combo、极限出餐、紧急清台。第三次紧急清台才提前收摊，避免七格软死局。

## 尸潮

内部仍然使用 0–100 压力，不创建大量僵尸 AI。

表现阶段：

1. 外围零星尸影
2. 尸群正在接近
3. 警戒 · 围栏受压
4. 冲击 · 红灯已亮
5. 危险 · 主灯不稳

防线、守夜岗位、电力和订单支援共同改变压力。表现层使用少量剪影、围栏、警报和灯光制造规模感。

## 白天文字事件

每个 DAY 只放 1 个主要事件，结构固定：

```text
背景 → 人物 → 问题 → 2–3 个选择 → 成本 / 风险 → 日志后果
```

选择必须满足：

- 至少有一条当前资源可承担的路径。
- 不允许单次选择毁掉长期存档。
- 后果写入余烬日志。
- 部分选择改变信任、伤病、防线、电力、口粮或药品。

## 幸存者

第一章固定 6 名长期角色：林夏、老周、阿禾、程医生、阿梁、小满。

每人只有足够产生记忆点的属性：

- 擅长岗位
- 精力
- 情绪
- 一条特性
- 信任 0–3
- 健康 / 轻伤 / 重伤 / 休养状态

不做稀有度、星级、装备、战力和抽卡。

轻伤会降低生产效率；休息可恢复。第一章不做永久死亡。

## 建筑

第一街段的可工作设施保持有限：

- 主灯塔
- 七格配给站
- 搜索站
- 修理工坊
- 诊疗站
- 守夜岗
- 宿营屋
- 广播亭

建筑修复必须同时产生数值、视觉或玩法变化，不能只有百分比升级。

## 余烬日志

日志是白天留存核心之一，记录：

- 昨夜结果
- 事件选择
- 建筑修复
- 资源变化
- 人物状态
- DAY 7 结局

日志最多保留最近一段合理长度，避免无限增长。

## 小灰

小灰主要提供情绪连续性，不设计成高收益宠物系统：

流浪猫 → 常驻猫 → 镇街猫。

## 每日挑战

每日挑战只保留 60 秒七格，不带白天经营。

- 日期映射固定 Seed。
- 主线存档隔离。
- `ES1-...` 挑战码。
- 本地 Canvas 分享卡。

## 明确不做

v0.4.0 不做：第二章、第四物资链、枪战、武器战力、僵尸寻路、开放世界、复杂 crafting、技能树、抽卡、联盟、PVP、体力墙、真实排行榜或大型后端。

## 最初版冻结标准

v0.4.0 视为“最初版”必须满足：

- NIGHT 1 → DAY 7 全流程自动贯通测试通过。
- 七格恒定为 7。
- 白天事件必须处理后才能进入黄昏。
- 资源至少有一个实际后果闭环。
- DAY 7 成功 / 失败均不死档。
- 主线可保存恢复；每日挑战不污染主线。
- `typecheck / tests / production build / Cloudflare dry-run` 全绿。

达到以上条件后冻结大系统，进入人工移动 QA、视觉、音效和投稿阶段。
