# Ember Street — v0.6.0 Submission Checklist

## 目标版本

- 产品：Ember Street / 余烬长街
- 版本：**v0.6.0 — Day Shift & Long Night**
- 定位：**30 天文字末日生存模拟 × 人物调遣 × 2D6 × 街区建设 × 夜间随机事件**
- 核心句：**天黑以后，每个决定都可能留到明天。**

## 构建门禁

```bash
npm install
npm run typecheck
npm test
npm run build
npm run cf:dry-run
```

功能分支与最终 `main` release commit 都必须 green。`cf:dry-run` 只代表部署配置验证，不代表真实线上部署。

## 核心体验

- 首次打开无需登录。
- 白天能够查看人物精力 / 伤病、物资箱、人口与六座建筑。
- 人物每天只能执行探索 / 维修 / 医疗 / 守备 / 广播 / 炊事 / 休息之一。
- 探索队 1–2 人；危险事件可继续深入、谨慎处理或撤退。
- 探索可能受伤、失踪；DAY11+ 在极端风险下允许永久死亡。
- 失踪者可搜救，确认死亡写入纪念墙。
- 救回普通居民增加真实人口，因此也提高口粮与炊事需求。
- 供餐覆盖随人口、厨师人数、阿禾专长和宿营屋等级变化。
- 六座设施最高 Lv3，升级改变实际规则能力。
- 黄昏锁岗后夜里不能重新调人。
- 普通夜 5 个主事件；尸潮夜 6 个；紧急事件额外插入。
- 每个夜间决策恰好 3 个选择。
- DAY10 / DAY20 / DAY29 必定尸潮。
- DAY29 为最后可操作日。
- DAY30 无操作，根据过去 29 天自动结算 13 个结局。

## 跑团判定

- 2–6 / 7–9 / 10–11 / 12+ 文案与规则一致。
- 优势 / 劣势分别为 3D6 取高二 / 低二。
- 修正来源可读：人物专长、信任、伤病、岗位 / 建筑和 Flags。
- 同 Seed 状态可复现。
- 已落地骰子保存后刷新不可重投。

## 移动端人工验收

重点：360×800、390×844、430×932。

- 无横向滚动。
- 核心按钮约 44px 或以上。
- 调遣、建筑、物资箱、探索地点在窄屏自然换行。
- 夜间事件正文和三个选项在手机上可读。
- 骰子与结果按钮不被底部遮挡。
- DAY30 结局和图鉴可滚动。
- reduced-motion 下规则仍可理解。

## 投稿素材建议

建议顺序：

1. 白天主街 + 人物调遣；
2. 派两人探索并遭遇随机事件；
3. 物资箱与建筑 Lv0→Lv3；
4. 5 人供餐时 1 人 / 2 人炊事的取舍；
5. 夜间三选一 + 2D6；
6. 紧急事件 / 尸潮；
7. 失踪搜救 / 纪念墙；
8. DAY29 最终尸潮；
9. DAY30 结局统计和 13 结局图鉴。

传播文案优先讲选择和人物，不再使用“七格守夜”作为当前版本卖点。

## 技术说明

- React 19 + TypeScript + Vite + Vitest
- seeded PRNG
- localStorage v3 + v2→v3 迁移
- 纯前端，无服务器 / AI API 运行依赖
- Cloudflare Workers Static Assets 配置

## 冻结范围

v0.6.0 发布后不继续增加第二章、枪械装备树、技能树、复杂 crafting、抽卡、PVP、联盟或大型 SLG。后续只允许阻断 Bug、平衡、移动端可读性、视觉 / 音效和投稿包装改进。
