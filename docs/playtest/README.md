# Playtest audit reports

This folder is generated by `tools/simulation/` for the v0.6.0 measure-first balance audit.

The baseline is intentionally descriptive rather than prescriptive. Read `baseline-summary.md` first, then the focused reports:

- `principle-audit.md`
- `community-scaling.md`
- `location-audit.md`
- `day29-audit.md`
- `content-repetition.md`
- `balance-anomalies.md`

Machine-readable CSV / JSON lives in `reports/playtest/`.

Do not mix large balance rewrites into the playtest-audit branch. Use the generated P0/P1/P2 evidence as the input to a separate balance branch.
