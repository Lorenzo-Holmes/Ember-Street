# Ember Street v0.3.0 — QA Matrix

## P0 阻断

- [ ] 首屏可进入，不白屏。
- [ ] 首单可用前三次罐头点击完成。
- [ ] 七格永远为 7。
- [ ] 满格出现紧急清台并确实释放空间。
- [ ] 第三次紧急清台进入当夜结算。
- [ ] DAY 1 天亮后可修搜索站。
- [ ] 可推进到 DAY 7。
- [ ] DAY 7 失败可重试 DAY 7。
- [ ] DAY 7 成功进入第一章完成状态。
- [ ] 刷新页面后主线存档可恢复。
- [ ] 每日挑战不覆盖主线存档。
- [ ] `npm run typecheck` 通过。
- [ ] `npm test` 通过。
- [ ] `npm run build` 通过。

## P1 手感

- [ ] 点击货架立即响应，无等待动画锁。
- [ ] 三合有清晰视觉 / 音频 / 震动反馈；API 不支持时自然降级。
- [ ] Combo 窗口会增长并会超时归零。
- [ ] 极限出餐有明显文案反馈。
- [ ] 尸潮压力增长能被守夜岗位实际影响。
- [ ] 建筑修复后可在画面中区分已修 / 废墟。
- [ ] 一键班表不修改资源，只修改岗位。
- [ ] 离线收益不在夜间推进游戏。
