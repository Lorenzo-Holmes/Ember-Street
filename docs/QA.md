# Ember Street v0.4.0 — Initial Release QA Matrix

## P0 自动化阻断

以下任何一项失败都不能合并 `main`：

- [x] 七格始终为 7。
- [x] 首局前三个罐头可完成第一次三合与首单。
- [x] 货架同类物资按 3 件一批，前两次点取不换品。
- [x] DAY 1 首单至少 30 秒。
- [x] 满格紧急清台释放空间；第三次才提前收摊。
- [x] 白天事件未解决时不能进入黄昏。
- [x] 事件选择会写入余烬日志。
- [x] 不可承担的事件选择会被禁用。
- [x] 口粮 / 药品 / 防线 / 电力可转成可读生存状态。
- [x] 低电力会让尸潮压力增长更快。
- [x] 药品可触发一次医疗请求额外等待时间。
- [x] 轻伤影响后续状态并可通过休息恢复。
- [x] DAY 1 可修搜索站并留下林夏。
- [x] NIGHT 1 → DAY 7 第一章自动贯通。
- [x] DAY 7 成功进入 `chapterComplete`。
- [x] 每日挑战 Seed / 挑战码可复现且不写主线。
- [x] 离线收益不上夜间进度。
- [x] `npm run typecheck` 通过。
- [x] `npm test` 通过。
- [x] `npm run build` 通过。
- [x] `npm run cf:dry-run` 通过。

> 勾选表示已有自动测试或 CI 验证。合并 `main` 后仍需再跑一次主干 CI。

## P0 人工主流程

发布前必须在真实浏览器 / Codespaces Preview 至少完整手玩一次：

- [ ] 首屏不白屏，10 秒左右可理解第一步。
- [ ] NIGHT 1 首单引导明显但没有教程弹窗阻塞。
- [ ] 天亮后能看懂“街区 / 行动 / 日志”三个入口。
- [ ] DAY 1 事件处理完成后，玩家能理解为什么可以进入黄昏。
- [ ] 黄昏页面能看懂今晚口粮、防线、电力与人员状态。
- [ ] DAY 2–6 不出现无法继续的资源硬锁。
- [ ] DAY 7 成功演出能清楚表达“第一章完成”。
- [ ] DAY 7 失败后可以重新准备，不会跳到 DAY 8。
- [ ] 刷新页面后当前主线能恢复。

## P1 夜间手感

- [ ] 订单之间确实有 2.5–3 秒喘息，不再连续闪烁刷新。
- [ ] 货架“本批 ×3 / ×2 / ×1”足够清楚。
- [ ] 三合反馈清晰，连续点击不锁 UI。
- [ ] Combo 和极限出餐反馈可见但不遮挡七格。
- [ ] 尸潮五阶段视觉变化能被感知。
- [ ] 低电力时压力更紧，但不是不可玩。
- [ ] 药品医疗容错触发时文案足够明显。
- [ ] 音效关闭 / 震动关闭立即生效。

## P1 白天阅读体验

- [ ] 生存状态优先显示语义而不是只显示数字。
- [ ] 事件正文一屏内能读完主要信息。
- [ ] 每个选择都显示成本 / 风险或明确“无消耗”。
- [ ] 不可选项解释原因。
- [ ] 余烬日志时间、标题、后果层级清楚。
- [ ] 幸存者能看到特性、信任、精力、伤病。
- [ ] 白天整体节奏明显比夜间安静。

## P1 移动端 viewport

逐个检查：

- [ ] 360×800
- [ ] 375×812
- [ ] 390×844
- [ ] 393×873
- [ ] 412×915
- [ ] 430×932

每档检查：

- [ ] 页面本身没有意外横向滚动。
- [ ] 七格没有裁切。
- [ ] 4 个货架单手可点。
- [ ] 主要按钮触控区约 44px 或以上。
- [ ] 底部操作不被 safe area 遮挡。
- [ ] 事件选择不卡在固定底栏下面。
- [ ] 日志长内容可正常滚动。
- [ ] 横屏不是目标模式，但不能白屏 / 崩溃。

## P1 生命周期与降级

- [ ] 切后台关键进度强制保存。
- [ ] 返回前台没有重复计时器。
- [ ] localStorage 不可用时至少能开始新游戏。
- [ ] Web Audio 不可用时不崩溃。
- [ ] Vibration 不可用时不崩溃。
- [ ] Clipboard 不可用时主线和分享卡生成不崩溃。
- [ ] `prefers-reduced-motion` 下循环动画减少。

## P2 内容一致性

- [ ] DAY 1–6 事件标题 / 文案与当天主题一致。
- [ ] DAY 1–7 预报和实际强度一致。
- [ ] 林夏、老周、阿禾、程医生、阿梁、小满按预期进入街区。
- [ ] 建筑解锁天数与 GDD 一致。
- [ ] 小灰每天最多推进一次。
- [ ] 第一章完成后灯火等级为 Lv.7。
- [ ] 分享卡仍能表达 DAY / 灯火 / 街区成长。

## 自动测试文件

- `tests/engine.test.ts`：七格、批次货架、节奏、建筑、资源夜间后果。
- `tests/narrative.test.ts`：事件、日志、选择成本、生存状态、伤病恢复。
- `tests/chapter-flow.test.ts`：NIGHT 1 → DAY 7 第一章贯通。
- `tests/feel.test.ts`：紧急清台、Combo。
- `tests/retention.test.ts`：离线、小灰、自动排班。
- `tests/challenge.test.ts`：每日 Seed 与挑战码。

## v0.4.0 最初版放行条件

1. 功能分支 CI 全绿。
2. 第一章贯通测试全绿。
3. 文档与实际 v0.4.0 规则一致。
4. 合并 `main` 后主干 CI 再次全绿。
5. `dev` 同步到同一个稳定提交。

完成 1–5 后，v0.4.0 即视为“最初版完成”。后续工作转为人工移动端 QA、视觉识别度、音效和投稿包装，不继续扩玩法系统。
