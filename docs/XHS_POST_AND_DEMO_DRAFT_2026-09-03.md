## 笔记正文草案

《余烬长街》是一个 30 天的城市灾后文字生存游戏。

你管理的不是军事基地，也不是一群越来越强的英雄，而是一条正在失去秩序的普通街区。

白天要决定谁出去探索、谁修东西、谁守街口；住进来的街区居民也会逐渐形成后勤、维修和守备轮值。人多了会多一份力量，也会多一张要吃饭的嘴。希望太低、长期吃不饱或者街区压力过高时，有人甚至会决定离开。

夜里，每个选择都会真正消耗白天留下来的东西。开门、救人、守住缺口，或者什么都不做，都可能让第二天变得不一样。

我希望它最后留下的感觉不是“我变强了”，而是：

“我们又撑过了一天，但为了撑过这一天，付出了什么？”

## 30–45 秒演示录屏顺序

### 0–4 秒：第一眼

- 打开最终小工具。
- 停在“据点”首页。
- 画面必须看见避难所主插画、DAY、资源和“安排今天”。
- 字幕可用：`30天。普通人。没有英雄。`

### 4–11 秒：今天谁做什么

- 点“安排今天”。
- 快速展示幸存者列表。
- 打开林夏详情，展示七个岗位是渐进展开而不是几十个按钮平铺。
- 选择“探索”。

### 11–18 秒：街区居民不是角色卡

- 回据点展示“街区居民”。
- 切换一次 `后勤 / 维修 / 守备`。
- 字幕：`多一个人，多一双手，也多一张嘴。`

### 18–27 秒：探索

- 进入“探索”。
- 让地点插画成为主体。
- 选择一个地点并出发。
- 事件出现后快速展示“继续深入 / 谨慎搜索 / 现在撤回”。

### 27–37 秒：夜间选择

- 切夜间事件。
- 画面保留事件/环境图、正文和三项选择。
- 重点拍到资源成本、2D6 或后果预览。
- 不需要完整掷骰流程，避免视频节奏拖慢。

### 37–45 秒：30天留下了什么

- 快切“记录”：街区日志 → 角色档案 → 纪念墙。
- 如有合适存档，最后停在 DAY29/DAY30 或结局画面。
- 结束字幕：`你能让这条街撑到第30天吗？`
