# Ember Street · 余烬长街

> **Seven slots. One last light.**  
> 只有七格，守住最后的灯火。

**Ember Street / 余烬长街** 是一款面向移动 Web 与小红书小工具场景的末日避难街轻量模拟经营游戏：白天修复街区、安排幸存者、准备物资；夜晚进入永久只有 **7 格** 的配给台，在幸存者请求与尸潮压力之间快速取舍。

当前比赛候选版本：**v0.3.0**。

## 核心循环

```text
白天经营
→ 修建筑 / 分岗位 / 看预报
→ 夜晚开张
→ 七格拿货 / 三合 / 交付请求
→ Combo / 极限出餐 / 防线压力
→ 天亮结算
→ 资源反哺街区
→ DAY 7 尸潮之夜
```

## 已完成内容

### 第一章：守住第一盏灯

- DAY 1–DAY 7 完整推进
- DAY 7 90 秒「尸潮之夜」章节高潮
- 失败不死档，可调整岗位与设施后重试
- 第一街段、主灯塔与 6 个可修设施
- 6 名可长期留下的幸存者
- 搜索 / 修理 / 诊疗 / 守夜 / 炊事 / 广播 / 休息岗位
- 一键按专长排班与尸潮班表
- 每日预报、停电、伤员、夜袭、尸潮等压力变化

### 七格核心玩法

- 4 个物资货架
- 永久 7 格配给台
- 罐头 / 医疗 / 电力三条物资链
- 三个同类物资自动合成
- 幸存者求助 / 防线急需两类请求
- 尸潮压力与请求耐心
- 8 秒 Combo 窗口
- 最后 15% 耐心完成请求触发「极限出餐」
- 满格时可主动「紧急清台」；第三次才提前收摊，避免软死局

### 留存与传播

- Seeded PRNG，核心随机可复现
- localStorage v2 存档与 v1 → v2 迁移
- 夜间存档节流 + 切后台强制保存
- 最多 6 小时的轻量离线备货，不离线推进尸潮
- 流浪猫 → 常驻猫 → 镇街猫「小灰」连续状态
- 每日标准化 60 秒挑战，与主线存档完全隔离
- `ES1-...` 带校验挑战码
- 本地 Canvas 生成 1080×1440 PNG 分享卡，无服务器依赖

## 技术栈

- React 19
- TypeScript
- Vite
- Vitest
- CSS / Web Audio / Canvas / localStorage

游戏核心位于 `src/game/`，React 主要承担表现层。尸潮采用「压力状态 + 少量视觉剪影」而不是大量独立僵尸实体，优先保证手机 WebView 的响应速度。

## 设计原则

1. **流畅 > 华丽**：七格点击反馈永远高于背景特效优先级。
2. **紧张但不恶意**：危机可提前准备，失败不造成死档。
3. **成长必须看得见**：建筑、主灯塔、幸存者与街区状态都直接出现在世界里。
4. **复杂度增长后自动化**：前期亲手分工，中期提供一键班表。
5. **纯前端即可完整游玩**：不依赖登录、服务器、AI API、PVP 或联网排行榜。
6. **第一章先做到完整**：比赛版聚焦 DAY 1–7，而不是铺一个空洞的 DAY 100。
