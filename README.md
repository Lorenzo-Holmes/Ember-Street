# Ember Street · 余烬长街

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Lorenzo-Holmes/Ember-Street?quickstart=1)

> **Every choice survives the night.**  
> **天黑以后，每个决定都可能留到明天。**

《余烬长街》是一款面向移动 Web 的 **30 天文字末日生存模拟 × 人物调遣 × 2D6 跑团判定 × 街区建设 × 夜间随机事件** 游戏。

当前版本：**v0.6.0 — Day Shift & Long Night**。

### Tutorial / New Player Experience v1

新建存档从正式 DAY1 开始，沿着一张可随时收起的开局便签，完成「清点口粮与材料 → 给一人安排工作 → 给另一人选探索路线并实际出发 → 主动结束白天 → 处理第一夜 → DAY2 查看日志」。教学不创建另一张地图，也不发放额外资源或替玩家选择答案。

引导随存档恢复；点击「跳过引导」立即回到普通游戏。没有教学字段的旧存档保持原进度，不强行补课。DAY2 打开日志后结束核心教学，后续伤病、建筑和人口变化只作一次轻提示。状态机和兼容规则见 [架构文档](docs/ARCHITECTURE.md)，流程取舍见 [GDD](docs/GDD.md)，验证结果见 [QA](docs/QA.md)。

## 核心循环

```text
清晨
→ 查看人物精力 / 伤病 / 人口
→ 调遣：探索 / 维修 / 医疗 / 守备 / 广播 / 炊事 / 休息
→ 需要时修整建筑；给探索者记下路线
→ 确认名单并锁定岗位，同路人员结伴出发
→ 探索队外出，可能受伤、失踪或死亡
→ 物资进入物资箱
→ 黄昏主动结束白天，结算工作与供餐
→ 夜晚处理按日期分档的三选一事件
→ 可能插入紧急事件和尸潮
→ 天亮
→ DAY 10 / 20 必定尸潮
→ DAY 29 最终尸潮
→ DAY 30 根据前 29 天自动结算 13 个结局
```

## v0.6.0 主要变化

### 七格系统退出主玩法

v0.6 的玩家路径不再使用七格配给台、四货架、三合订单、Combo 或夜间倒计时。夜晚改成事件驱动：读清楚问题，再在三个方案中决定是赌人、花资源，还是承担长期后果。

### 白天人物调遣

每名可行动幸存者每天只能承担一个主要岗位：

- **探索**：带回口粮、药品、材料、零件与路线情报；人物状态会直接影响风险。
- **维修**：加固防线，并让工坊在夜间建筑事故中发挥作用。
- **医疗**：使用诊疗站和药品处理伤势。
- **守备**：降低紧急事件和尸潮风险。
- **广播**：建立外界联系、寻找幸存者，并可能开启军方救援路线。
- **炊事**：按人口提供供餐能力，而不是固定“一人做饭全队吃饱”。
- **休息**：恢复个人精力。

确认名单后岗位锁定；探索已经出发就不能重写当天安排，夜里不能临时换人。

### 探索、生还与永久死亡

探索者在名单上选路，写在同一地点的人结伴出发。地点危险、人物精力、伤病、专长、路线屋等级、同行人数与路线情报共同决定风险。

- DAY 1–5 不发生永久死亡。
- DAY 6 起高危失败可能导致失踪。
- DAY 11 起，极险环境叠加严重状态和灾难结果时，人物可能永久死亡。
- 探索事件始终允许撤回：今天什么都没拿到，但人回来了，也是完整选择。

### 人口相关供餐

普通角色基础炊事能力约为 **2.5 人份**，阿禾约为 **3.5 人份**；宿营屋 / 公共厨房等级再提高效率。

| 供餐覆盖 | 伙食 | 精力恢复 | 希望 |
|---:|---|---:|---:|
| 0% | 冷食 | +4 | 连续不足后下降 |
| <60% | 勉强开伙 | +8 | -1 |
| 60–99% | 普通热食 | +11 | 0 |
| 100–129% | 饱腹 | +15 | +1 |
| ≥130% | 充分饱腹 | +19 | +2 |

最终伙食等级同时受 **口粮是否充足** 和 **炊事覆盖率** 限制。

### 物资箱与建筑 Lv0–3

普通长期资源保持为：

- 口粮
- 药品
- 电力
- 材料
- 零件
- 希望（街区状态）

六座核心设施：搜索站、修理工坊、诊疗站、守夜岗、宿营屋、广播亭。每座最高 Lv3，升级不仅提高数字，还会解锁路线情报、重伤治疗、夜间事故减伤、尸潮预警、公共厨房和远距联络等规则能力。

### 夜晚：逐步增加的事件 + 紧急事件 + 尸潮

普通事件预算为 DAY1–5 两件、DAY6–23 三件、DAY24–28 四件；尸潮片段替换部分普通事件，紧急事件另外插入。DAY29 使用固定最终尸潮序列。新手第一夜只优先安排已有的「围栏外有人敲门」，不改变事件总数、尸潮与紧急事件概率。

所有需要玩家处理的夜间事件固定 **3 个选项**：

1. 人物 / 冒险方案：通常进入 2D6。
2. 资源 / 稳定方案：消耗物资换稳定结果。
3. 保守 / 长期方案：降低眼前风险，但留下 Story Flag 或延迟代价。

`Night Event Visual Upgrade v1` 让事件数据直接声明语义化 `visualKey`，夜间页面只通过集中映射取得已批准的正式素材，不再把未知事件统一显示成宿营屋总览。当前 51 个静态夜间定义及按人物生成的医疗 / 离队危机均已覆盖；首批视觉区分门外来访、临时医疗、负伤归来、室内争执与街外威胁，并扩展到空位、失窃、安静、离开、断电、广播、建筑受损和火险。普通排程会优先避开本夜已出现及最近两夜用过的通用视觉；若只有一个剧情正确的类别，则保留正确画面而不随机换成不相干插图。

`Audio Interaction & Notebook Motion V2` 在既有听觉层上继续区分“世界事件 / 行动结算 / 纸本交互”：夜间 `audioKey` 现在包含独立感染者叫声，尸群接近与结构撞击不再共用一种声音；Night 1 敲门和野狗改用经许可登记、裁切压缩后的真实环境素材。探索只有在口粮 / 药品 / 材料 / 零件确实增加时才播放克制的翻找收纳声；撤退或空手不会误报成功。

底部“据点 / 建筑 / 幸存者 / 记录”一级导航使用约 220ms 的轻量纸页掀动并配短翻页声，同一页重复点击不会重复播放；探索路线从一个地点切到另一个地点时，地点名称周围的红笔圈由 SVG stroke 真实画出，并同步短笔划声。交互 cue 使用独立短音通道，不主动压低 BGM，并带限流；`prefers-reduced-motion` 会关闭明显位移 / 旋转动画。音频仍只能在玩家第一次“开始 / 继续”点击后解锁，切后台暂停，文件缺失或解码失败不会阻塞任何选择。

声音设置继续使用独立的 `ember-street-audio-v1` 本地偏好，不进入 `GameState`，因此旧存档不需要迁移。五个阶段 BGM 仍来自本地审核后的妙响母带衍生版本；6 个高辨识度短音效由 `scripts/import-free-sfx-v2.mjs` 从已锁定的 Mixkit Free License 条目可复现导入，来源与处理哈希记录在 `docs/audio/SFX_SOURCE_LEDGER_V2.md`。普通 Web / Cloudflare 构建继续使用 `public/assets/audio/` 中的 MP3；小红书小工具因上传白名单不接受音频扩展名，`build:minitool` 会把同一批 30 个 MP3 在构建期转换为外置 JS 中的 Base64 数据，由 Web Audio `decodeAudioData()` 按需解码播放，并从最终 ZIP 删除全部 MP3。两种构建都不联网取音频。

DAY 10、DAY 20、DAY 29 必定触发尸潮；普通夜尸潮由 Seed、日期、防线、电力、守备与情报共同决定。

### 2D6

- 2–6：失败
- 7–9：部分成功
- 10–11：成功
- 12+：大成功
- 优势：3D6 取高二
- 劣势：3D6 取低二
- 双六 / 双一保留特殊后果
- Seeded PRNG 保证同一状态可复现
- 已经落地的骰子不能通过刷新重投

### DAY 29 / DAY 30

**DAY 29 是最后一个可操作日。** 白天仍可选择最后一次高风险探索，夜晚进入最终尸潮，并得到：

- perfect
- held
- damaged
- breached

**DAY 30 完全无操作。** 游戏读取过去 29 天的人口、死亡、救援、希望、建筑、广播、路线、主灯与 DAY 29 结果，自动进入 13 个结局之一。

13 个结局：黎明车队、灯火长街、第二个灯塔、带他们回家、我们留下、向南、最后一次广播、一条小街、灯灭了、空街、北门之后、最后的守灯人，以及隐藏结局 **DAY 31**。

结局图鉴保存在独立 MetaSave 中，重新开档不会清除已经发现的结局。

## v0.6.x 冻结原则

1. 白天给玩家控制权，夜晚让玩家承担白天决定的后果。
2. 人物一天只能承担一个主要岗位。
3. 救人既增加劳动力，也增加口粮、医疗与后勤压力。
4. 探索允许永久死亡，但不允许无提示的纯 RNG 猝死。
5. 炊事使用人口相关供餐覆盖率，不新增“厨艺货币”。
6. 夜晚不再使用读文本倒计时。
7. DAY 29 是最终尸潮，DAY 30 只结算。
8. 第一章固定 13 个结局，其中 1 个为隐藏结局。
9. 不增加枪械装备树、抽卡、PVP、大型 SLG 或第四资源链。
10. 移动端优先，交互目标至少约 44px，支持 `prefers-reduced-motion`。
