# Ember Street UI v1 components

Presentation components under this directory follow `docs/UI_UX_V1.md`.

Rules:
- mobile-first, 390×844 baseline;
- illustration first, UI second;
- one screen, one primary decision;
- `据点 / 探索 / 幸存者 / 记录` are the only first-level navigation targets;
- named survivors and `街区居民` are separate systems;
- A-series identifiers remain internal to `visualAssets.ts` and are never rendered to players.
